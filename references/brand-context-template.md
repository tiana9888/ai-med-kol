# Brand Context Template

Use this when the user has not provided enough campaign context.

## Minimum Context To Request

Ask for the fewest missing items needed to proceed:

- Brand/product name.
- Product category and what it actually does.
- Target audience: decision maker, user, patient/family, doctor, hospital manager, partner, investor, public.
- Campaign objective: awareness, trust, launch, leads, event, education, recruitment, reputation.
- Platform and format: 视频号, 小红书, 抖音, B站, 公众号, live, event recap, interview, short video.
- KOL list or desired KOL type.
- Must-say points and must-not-say points.
- Evidence available: cases, data, demos, reports, certificates, expert quotes, customer stories.
- CTA.
- Compliance sensitivity and review process.

## Optional Deep Context

- Brand tone: professional, warm, founder-led, expert-led, pragmatic, disruptive, patient-friendly.
- Competitors or benchmark accounts.
- Existing content assets.
- Product screenshots or demo workflow.
- Sales objections.
- Audience misconceptions.
- Launch timeline and approval deadlines.
- Regions, diseases, departments, or hospital types involved.

## If Context Is Thin

Proceed with assumptions only if the user asks to move fast. Label assumptions clearly and make the output easy to revise.
